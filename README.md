# Valentine's Day Proposal Web Page

This web page serves as a fun, interactive Valentine's Day proposal. It features animated visuals, inviting buttons, and playful interactions, making it a delightful way to ask someone to be your Valentine.

## Features
- **Beautiful Animated Background**: A gradient background with floating hearts creates a romantic atmosphere.
- **Engaging UI**: The main question "Will you be my Valentine?" is prominently displayed.
- **Interactive Buttons**:
  - **Yes** button: Click to redirect to a celebration page (you will need to create `celebration.html`).
  - **No** button: Moves randomly around the screen to playfully dodge clicks.
- **Floating Emojis**: Fun emoji animations float upward every second, adding a festive touch.

## Technologies Used
- **HTML**: Structure of the web page.
- **CSS**: Styling and animations.
- **JavaScript**: Interactivity and dynamic content.
- **Google Fonts**: Usage of the 'Pacifico' font for a stylish look.
